Brightness Syncer

Hello! Brightness Syncer is a Windows application that uses your device’s webcam to measure the ambient light and adjusts the brightness of your monitor accordingly. This helps reduce eye strain and prevents potential damage.
Features

    Ambient Light Measurement: Using your device's webcam, the ambient light is measured, and the monitor's brightness is adjusted accordingly.
    Customizable Timing: You can set how often the monitor brightness updates (e.g., every 30 minutes or every hour).
    Universal Compatibility: Works with any standard webcam, even the built-in webcam on your laptop.
    Health Benefits: Helps reduce eye strain and prevents headaches from prolonged computer use.

Target Audience

This software is beneficial for everyone, including:

    Children: If you're concerned about your child's eye health due to extended computer use.
    Office Workers: If you experience headaches or eye strain from long hours of computer work.
    Programmers and Graphic Designers: If your eyes get red and irritated from prolonged monitor use.
    Gamers, Editors, and YouTubers: For anyone who uses the computer frequently.

How to Use

    First, download the entire repository, then run the file brightness Syncer.exe. After a few seconds, the graphical interface will be activated.
    The graphical interface has two sections: manual and automatic.
    In the manual section, you can manually adjust the monitor brightness in real-time based on the ambient light.
    In the timer section, first select the time unit (minutes or hours), then set the duration, and use the "Activate Timer" button to start the timer. The program will automatically adjust the brightness in a loop at the specified time interval.
    When the timer is active, the timer button text will change to "Timer is active."
    To change the timer duration, first turn off the timer, then reactivate it to apply the changes.
